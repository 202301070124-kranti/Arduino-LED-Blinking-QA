# Arduino LED Blinking

## Project Description
This project demonstrates a basic Arduino LED blinking program.

## Components Required
- Arduino board
- LED
- Resistor
- Connecting wires

## Working
The LED is switched ON and OFF at regular intervals using the Arduino digital output.

## QA Process
The project uses GitHub Issues to document QA problems, root causes and corrective actions.

## Issues Identified
1. LED does not blink
2. Blinking speed is not as expected
3. Code documentation needs improvement
4. Changes are difficult to trace
